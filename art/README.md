# Art sources

Aseprite sources, mirroring `data/textures/` (e.g. `art/creatures/dragon_adult.aseprite` →
`data/textures/creatures/dragon_adult.png` + `.anim.json`). Export with `python3 tools/export_art.py`.
Conventions, required animation tags and the style guide are in [docs/ART.md](../docs/ART.md).
