# Art sources

- `brand/`: the logo, emblem and brand guide (`brand-guide.html`), generated by `tools/brand_logo.py`.
- `reference/`: what maps are traced from (`village-map2.webp`, Millbrook, via `tools/village_map.py`).
- `3d/`: the parked 3D character rig (`wanderer.json`; docs/ART.md "3D to sprites").

Almost everything in `data/textures/` is drawn by the generators in `tools/` (`gen_placeholder_art.py`
runs them all). Hand-drawn Aseprite sources, if any come, mirror `data/textures/` (e.g.
`art/creatures/pig.aseprite` → `data/textures/creatures/pig.png` + `.anim.json`); export them with
`python3 tools/export_art.py`. Conventions, animation tags and the style guide are in
[docs/ART.md](../docs/ART.md).
